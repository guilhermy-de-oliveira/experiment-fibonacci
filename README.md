# Fibonacci Sequence and the Golden Ratio

A simple Python project that explores the relationship between the Fibonacci sequence and the golden ratio through mathematical calculations and visualizations.

## About the Project

This project was created as a learning exercise to practice Python programming and explore some interesting mathematical concepts.

**This is my first Python application.** It is not intended to be a professional or fully optimized solution, but rather a practical opportunity to learn, experiment, and understand how Python can be used to solve problems and create visual representations of mathematical ideas.

The project focuses on the connection between consecutive Fibonacci numbers and the golden ratio, as well as the construction of a spiral inspired by the Fibonacci sequence.

## Features

- **Fibonacci Sequence:** Calculates a specified number of Fibonacci terms.
- **Golden Ratio Convergence:** Plots the ratios between consecutive Fibonacci numbers to illustrate their convergence toward the golden ratio.
- **Golden Spiral Visualization:** Draws Fibonacci squares and circular arcs to create a spiral-like representation.

## Technologies Used

- **Python** — Main programming language.
- **Matplotlib** — Used to create the plots and geometric visualizations.
- **Math** — Used to calculate the golden ratio.

## Requirements

Make sure you have Python installed on your machine.

Install the required external library using pip:

```bash
pip install matplotlib
```

The `math` library is part of Python's standard library and does not need to be installed separately.

## How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/guilhermy-de-oliveira/experiment-fibonacci.git
   ```

2. Navigate to the project directory:

   ```bash
   cd PROJECT-DIRECTORY
   ```

3. Run the Python script:

   ```bash
   python main.py
   ```
   
4. Enter an integer greater than 2 when prompted.

The program will calculate the Fibonacci sequence and display two visualizations: a graph showing the convergence of consecutive Fibonacci ratios toward the golden ratio and a spiral constructed using Fibonacci-sized squares and circular arcs.
